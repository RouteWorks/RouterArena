## What each one is

### `nadir-cascade-v3-verifier` — the real Nadir architecture

Wide-deep-asymmetric classifier (trained on production traffic) feeds a tier in `{simple, medium, complex}`. A cross-encoder verifier (cheap response generated, then scored) gates the simple-tier picks: if `verifier_score >= 0.70` the cheap answer is accepted, otherwise the prompt escalates to mid. Tier is mapped to a fixed three-model Claude pool:

- `simple` -> `claude-haiku-4-5`
- `medium` -> `claude-sonnet-4-6`
- `complex` -> `claude-opus-4-6`

Reported scores (offline, against RouterArena's cached results via the same scorer the leaderboard uses):

- Arena score: **0.7118**
- Accuracy: **0.7371**
- Cost / 1K queries: **$0.6841**
- Verifier-escalation rate: **0.967** (over the 7,061 simple-tier prompts the verifier actually scored)
- Calibrated threshold tau: **0.70** (best of a 14-point sweep from 0.30 to 0.90)

### `nadir-cheapest-strategy-E` — the cost-minimization baseline

Not a smart router. For each prompt we examine the cached model set in RouterArena and pick the cheapest by output `$/M`, alphabetical tie-break. Strategy E adds a length-budget `max_tokens` cap (R2-Router playbook):

- prompt len < 500 chars -> 256 tokens
- 500-2000 chars -> 512
- > 2000 chars -> 1024

Reported scores: arena ≈ 0.7043, accuracy ≈ 0.6996, cost / 1K ≈ $0.5180. Submitted as a deliberate baseline so reviewers can see what pure cost arbitrage scores against the cascade.
